## Technologies used in my projects

Python, JavaScript, HTML, CSS, Flask, Express, SQLAlchemy, SQLite, Jinja2, and Node.js.

## Selected projects

### [MyMoney Hub](https://github.com/OP-glich/MyMoneyHub)

An offline-first Windows app for managing personal finances in Namibian dollars. It brings spending, budgets, protected savings, lending, receipts, and sales records into one local workspace. Built with Python, Flask, SQLAlchemy, SQLite, Jinja2, and vanilla JavaScript.

### [Surplus Window](https://github.com/OP-glich/surplus-window)

A local food-donation coordination app for a fictional Windhoek bakery and community kitchens. Kitchens reserve available portions for collection, while the donor confirms handovers and sees where every portion went at the deadline. Built with Node.js, Express, SQLite through better-sqlite3, and plain HTML, CSS, and browser JavaScript.

### [Northstar student registration](https://github.com/OP-glich/MyFirstWebsite)

A responsive, three-step registration front-end demo with field validation, review before confirmation, and a downloadable text receipt. Built with HTML, CSS, and vanilla JavaScript. It does not submit applications to a real institution.
